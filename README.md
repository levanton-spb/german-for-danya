# 🇩🇪 Deutsch Lerner — Telegram Bot

Игровой бот для изучения немецкого языка. Ребёнок занимается с преподавателем, а вы загружаете
пройденный материал в виде картинок, слов и фраз. Бот превращает это в тест-игру с 3 режимами.

---

## 📦 Возможности

### 3 режима игры (по 20 заданий):
| Режим | Описание |
|-------|----------|
| 🖼 **Картинка → слово** | Показывается картинка, нужно выбрать немецкое слово из 4 вариантов |
| 🇷🇺 **Слово → перевод** | Показывается русское слово, нужно выбрать немецкий перевод из 4 вариантов |
| ✏️ **Фразы (ввод)** | Показывается немецкая фраза, нужно ввести перевод на русском |

### Для администратора (преподавателя):
- Загрузка уроков через `/new_lesson Название`
- Добавление вопросов с картинками, словами и фразами
- Управление уроками (список, удаление)

### Для ученика:
- Выбор урока и типа заданий
- Прохождение 20 вопросов
- Результат и оценка после каждого раунда
- История всех результатов

## 🚀 Быстрый старт

### 1. Получите токен бота
Напишите в Telegram: [@BotFather](https://t.me/BotFather)
```
/newbot
→ придумайте название, получите токен
```

### 2. Узнайте свой Telegram ID
Напишите: [@userinfobot](https://t.me/userinfobot)

### 3. Настройка проекта
```bash
# Клонируйте/скопируйте папку проекта
cd German\ for\ Danya

# Установите зависимости
pip install -r requirements.txt

# Создайте .env из шаблона
cp .env.example .env
# Отредактируйте .env — вставьте токен и свой ID
```

### 4. Запуск
```bash
python bot.py
```

## 📖 Как пользоваться

### Админ (преподаватель):
1. Нажмите `🛠 Админ-панель` (доступна только вашему ID)
2. Нажмите `➕ Загрузить урок` или отправьте `/new_lesson Название урока`
3. Выберите тип вопроса, который хотите добавить:
   - **Картинка → слово** — отправьте фото с подписью: `der Hund|собака|die Katze|das Pferd|der Vogel`
   - **Слово → перевод** — отправьте: `der Tisch|стол|der Stuhl|das Bett|die Tür`
   - **Фразы** — отправьте: `Ich heiße Anna.|Меня зовут Анна.`
4. После добавления всех вопросов отправьте `/done`

### Ученик:
1. Нажмите `🎮 Играть`
2. Выберите тип заданий
3. Выберите урок
4. Отвечайте на вопросы. После 20 заданий — результат с оценкой

## 🐳 Деплой на Railway (бесплатно)

1. Залейте проект в GitHub репозиторий
2. Зайдите на [Railway.app](https://railway.app) → New Project → Deploy from GitHub repo
3. В настройках проекта добавьте переменные окружения:
   - `BOT_TOKEN` — ваш токен
   - `ADMIN_ID` — ваш Telegram ID
4. Railway сам определит `requirements.txt` и запустит `python bot.py`

Проверьте, что в корне проекта есть файл `railway.json` (необязательно) или просто `requirements.txt`.

## 🐳 Или деплой через Docker на VPS

```bash
# Соберите образ
docker build -t german-bot .

# Запустите с переменными окружения
docker run -d \
  -e BOT_TOKEN=ваш_токен \
  -e ADMIN_ID=ваш_id \
  -v bot_data:/app/data \
  --restart always \
  --name german-bot \
  german-bot
```
